# 🎙️ Wan2.1 + InfiniteTalk (v1.0 基线版本) 评测报告与归档记录

## 📌 1. 版本概况

**v1.0** 是本项目建立的首个全功能数字人流水线，验证了阿里 **Wan2.1 (14B)** 底座搭配腾讯 **InfiniteTalk** 在高质量真人歌唱与对口型上的可行性。

- **核心底座**：Wan2.1-I2V-14B (BF16)
- **音频声学编码器**：Chinese-Wav2Vec2 (Tencent Games 2021)
- **人声伴奏分离**：HTDemucs (Meta 2022)
- **输出视频规格**：原生 25 fps，提供 480P 与 720P 两种画质模式
- **后处理机制**：无高刷插帧，无声画渐变淡出

## ⚠️ 5. v1.0 暴露的核心痛点（促成 v1.1 升级的原动力）

在 v1.0 实测中，我们发现了影响成片品质的三大短板：
1. **HTDemucs 分离残留导致“唇形微颤”**：
   - HTDemucs (SDR 9.0 dB) 消除配乐不够干净，当歌曲出现重低音鼓点或密集钢琴和弦时，Chinese-Wav2Vec2 会把伴奏误判为人声起伏，导致歌手在不发声的间隙出现不自然的微小嘴唇抽动。
2. **25fps 原生帧率在大开合唱腔时有顿挫感**：
   - 歌唱视频不同于普通说话，嘴型与下颌开合剧烈，25fps 在快速咬字切换时帧间位移较大，缺乏丝滑的运动连贯性。
3. **结尾生硬中断**：
   - 歌曲截断处声画瞬间骤停，缺乏影视级的渐隐淡出质感。

*这些痛点直接推动了后续 **v1.1 (BS-RoFormer + 60fps RIFE + 声画淡出)** 的重大架构升级。*
