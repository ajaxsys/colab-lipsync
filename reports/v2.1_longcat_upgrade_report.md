## 🎯 1. 攻坚背景与核心硬伤

此前在原生 BF16 精度下跑出了 LongCat 1.6 的 30 秒全片，虽然解决了 INT8 量化彩斑噪点问题，但人工质检发现两大视觉与拟真度硬伤：
1. **第 0.0 秒未唱先大张口**：在音频前奏纯伴奏段，麦克风微弱底噪激活了 Whisper-Large-v3 声学编码器的高频感知，导致人物在视频首帧便露出深邃口腔，缺乏抒情歌手起势的自然蓄势美感；
2. **发音“你”时口型撕扯过度**：在第 3.2 秒唱响首句“你”时，默认 `audio_guidance_scale=1.0` 使得驱动力过大，下颌过度向下撕拉，口型开合过于夸张，品质明显不及 v1.1（Wan2.1 14B + InfiniteTalk）柔美自然。

## 🔬 2. v2.1 核心算法与工程调优

### 2.1 双轨前奏能量门控（Intro Silence Gating）
- **机理**：在音频特征提取阶段，计算前 2.5 秒与全局音频的 RMS 能量方差比：
  $$\text{RMS}_{\text{intro}} = \sqrt{\frac{1}{N}\sum_{i=1}^{N} x_i^2}$$
  实测前奏段底噪 RMS 仅为 `0.0001`，远低于歌声平均值 `0.0635`。
- **作用**：门控将前 2.5s 伴奏段强制置零，Whisper 输出纯净静默条件向量，使人物在首帧及前奏段维持绝对自然安详的闭合/微抿待唱神态。

### 2.2 唇动张力与 LoRA 混合收敛调优
- **声学引导权重**：`audio_guidance_scale` 从 `1.0` 调降至 **`0.7`**，显著收敛下颌夸张下坠，抑制唇部边缘过度拉扯；
- **双 LoRA 动态混合比**：将 DMD（强发音张力）与 OPSD（平滑时序对齐）的混合系数 `mix_alpha` 设为 **`0.65`**（在第 0~4 步前向中融合），既保留歌词高保真咬字，又赋予歌唱面容如微风轻拂的优雅开合。

### 2.3 A100-40GB 原生 BF16 算子级显存深度优化
为了在 40GB SXM4 显卡上**绝不降级 INT8**、全程保持纯净 BF16 运行：
1. **Text Encoder 宿主机 RAM 驻留**：将 9.5GB UMT5-XXL 放在 83GB CPU 内存中，生成 Prompt 仅需 3 秒，释放 9.5GB GPU 显存；
2. **C++ 原生融合 `F.rms_norm`**：替换原本在 BF16 下强制转换为 FP32 导致的 488MB 中间显存碎片，单 Block 节约 1GB 瞬时显存；
3. **KV-Cache 动态 CPU 卸载（`offload_kv_cache=True`）**：将 AVC 连贯段的 30 层缓存动态置于 CPU，显存占用稳定在 **28.5GB / 40.0GB**，留足 >11.5GB 安全余量。
